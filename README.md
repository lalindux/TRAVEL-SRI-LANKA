# 🌴 Explore Ceylon - Sri Lanka Travel Guide

A responsive, lightweight, single-page web application designed to help travelers explore popular tourist destinations, view location details, filter categories, and watch scenic travel video clips across Sri Lanka.

![Explore Ceylon Banner](https://images.unsplash.com/photo-1546708973-b339540b5162?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Features

- **Responsive Navigation Bar:** Smooth scroll navigation with a custom logo and a mobile-friendly hamburger menu.
- **Hero Search Section:** Search bar allowing users to filter travel spots by place name, district, or description in real-time.
- **Dynamic Category Filtering:** Filter destinations instantly by categories such as *Historical*, *Nature & Mountains*, and *Beaches*.
- **Interactive Destination Cards:** 
  - High-quality image previews.
  - Category badges & location/district details.
  - Direct integration with Google Maps via "View Map" links.
- **Travel Video Clips:** Embedded YouTube cinematic travel films and region-specific highlight videos.
- **Favicon & Logo Integration:** Custom brand identity included in the navigation header and browser tab.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for page structure.
- **CSS3:** Custom styling, Flexbox, Grid layout, CSS Variables, and CSS animations.
- **JavaScript (ES6):** Client-side dynamic rendering, search functionality, category filtering, and DOM manipulation.
- **FontAwesome:** Icons for navigation and UI elements.
- **Google Fonts:** Poppins font family.
